2026

  1. SBLP
    Strong Normalization for Well-Typed Parsing Expression Grammars
    Guilherme Augusto Anício Drummond Nascimento, Elton Máximo Cardoso, Samuel da Silva Feitosa, and 1 more author
    In Proceedings of the XXX Brazilian Symposium on Programming Languages (SBLP 2026)(to appear) , 2026
    Awarded Abs Bib Code

    Best Paper Award at SBLP 2026

    Parsing Expression Grammars (PEGs) are a deterministic formalism for describing syntax that has gained wide adoption in practice. We show that well-typed PEGs always terminate, using a logical-relations argument inspired by the strong normalization proof for the simply typed lambda-calculus. The proof is mechanized in the Agda proof assistant.

  2. SBLP
    A Mechanized Formalization of MicroKanren in Agda
    Eduardo Henke and Rodrigo Ribeiro
    In Proceedings of the XXX Brazilian Symposium on Programming Languages (SBLP 2026)(to appear) , 2026
    Abs Bib Code

    We present a machine-checked formalization of microKanren in the Agda proof assistant. Building on McBride’s accumulating most-general unifier, we develop a coinductive stream model for non-deterministic search with machine-verified soundness, completeness, and maximality for the unification goal.

  3. SBLP
    A Mechanized Semantics for eBPF and its Applications in Program Verification
    Marcos Geraldo Braga Emiliano and Rodrigo Ribeiro
    In Proceedings of the XXX Brazilian Symposium on Programming Languages (SBLP 2026)(to appear) , 2026
    Abs Bib Code

    This paper presents a mechanized formalization of eBPF in Lean 4, comprising a small-step operational semantics over 64-bit machine words and flat byte-addressed memory, a separation logic over register files and partial heaps, and a sound frame rule with a semantic soundness theorem connecting the derivation system to the operational model.

  4. SBMF
    A Machine-Checked Formalization of the Greibach Normal Form Conversion for Context-Free Grammars
    Rodrigo Ribeiro
    In Formal Methods: Foundations and Applications – 29th Brazilian Symposium on Formal Methods (SBMF 2026)(to appear) , 2026
    Abs Bib Code

    The Greibach Normal Form (GNF) is a canonical form for context-free grammars in which every production begins with a terminal symbol. We present a formalization of the GNF conversion in which each stage carries a constructive proof that it preserves the language of the grammar it transforms.

  5. SBMF
    A Machine-Checked Formalization of the Pumping Lemma for Context-Free Languages via Pushdown Automata
    Rodrigo Ribeiro
    In Formal Methods: Foundations and Applications – 29th Brazilian Symposium on Formal Methods (SBMF 2026)(to appear) , 2026
    Abs Bib Code

    We present a machine-checked formalization, in the dependently typed language Agda, of the pumping lemma for context-free languages, proved through pushdown automata. The theorem is stated about an arbitrary pushdown automaton and its empty-stack language.

  6. SBMF
    Mechanizing a Resource-Aware Hoare Logic with Asymptotic Cost Assertions in Lean
    Gabriel Araújo Saldanha and Rodrigo Ribeiro
    In Formal Methods: Foundations and Applications – 29th Brazilian Symposium on Formal Methods (SBMF 2026)(to appear) , 2026
    Abs Bib Code

    Resource-aware Hoare logics internalize cost reasoning through cost-annotated triples, but their metatheory typically rests only on pen-and-paper proofs. We present a mechanization in Lean of one such logic, covering its cost-instrumented semantics, its cost logic and its verification condition generator, together with a relative-completeness result absent from the source.

  1. CGO
    Honey Potion: An eBPF Backend for Elixir
    Kael Soares Augusto, Vinícius Pacheco, Marcos A. Vieira, and 2 more authors
    In Proceedings of the 23rd ACM/IEEE International Symposium on Code Generation and Optimization (CGO ’25), 2025
    Abs DOI Bib Code

    This paper describes Honey Potion, a compiler that compiles Elixir to eBPF binaries. Translation must not only preserve semantics but also satisfy the eBPF verifier, which requires proofs of in-bounds memory accesses and termination; the translator relies on ensured termination to implement constant propagation, type specialization and partial evaluation.

  2. SBLP
    Pest Control: A formal model of the Pest parser generator
    Guilherme Daher, Elton Cardoso, Leonardo Reis, and 1 more author
    In Proceedings of the XXIX Brazilian Symposium on Programming Languages (SBLP 2025), 2025
    Abs DOI Bib

    Pest is the most used PEG-based parser generator for Rust, and its grammars support new operators for repetition and handling an implicit stack during parsing. We propose a formalization of these constructs and extend a type inference algorithm which guarantees that all well-typed Pest-style grammars do not loop on inputs.

    Mallku Soldevila, Rodrigo Ribeiro, and Beta Ziliani

    Abs DOI Bib Code

    Type-based Termination Analysis for Parsing Expression Grammars
    Elton M. Cardoso, Daniel F. Pereira, Regina S. M. A. Paula, and 2 more authors
    In Proceedings of the 38th ACM/SIGAPP Symposium on Applied Computing (SAC ’23), 2023

  2. SBLP
    A Haskell Library for Adaptable Parsing Expression Grammars

    Abs DOI Bib Code

    Adaptable Parsing Expression Grammar (APEG) is a formal model for describing languages which provide a mechanism to extend its own syntax during parsing. We review the syntax and semantics of APEG and discuss the implementation of a Haskell library for building parsers for extensible languages.

  3. SBLP
    A Verified Operational Semantics for Regular Expression Parsing
    Elton M. Cardoso, Leonardo V. S. Reis, and Rodrigo G. Ribeiro
    In Proceedings of the XXVII Brazilian Symposium on Programming Languages (SBLP 2023), 2023
    Abs DOI Bib Code

    Instead of using derivatives or generating a finite state machine for a given regular expression, we develop an operational semantics for parsing regular languages in which a RE is a program executed over the input string. We show that the semantics is sound w.r.t. a standard inductive semantics for REs. All results are formalized in Coq.

  3. SBLP
    A Type-Directed Algorithm to Generate Random Well-Formed Parsing Expression Grammars
    Elton M. Cardoso, Daniel Freitas Pereira, Regina Sarah Monferrari Amorim Paula, and 2 more authors

  4. SBMF
    A Sound Strategy to Compile General Recursion into Finite Depth Pattern Matching
    Maycon J. J. Amaro, Samuel S. Feitosa, and Rodrigo G. Ribeiro
    In Formal Methods: Foundations and Applications – 25th Brazilian Symposium on Formal Methods (SBMF 2022), 2022
    Abs Bib Code

    We propose a technique to unroll recursive programs in functional languages to create terminating versions of them, prove that the strategy terminates, and use property-based testing to build confidence that semantics is preserved. The strategy can be used to compile functional languages to restrictive targets such as eBPF and smart contracts.
