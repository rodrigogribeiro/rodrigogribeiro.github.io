Sou professor do Departamento de Computação da Universidade Federal de Ouro Preto (UFOP), em Minas Gerais, onde leciono desde 2008.

Graduei-me em Ciência da Computação pela UFOP em 2005 e obtive o mestrado (2007) e o doutorado (2013) pela Universidade Federal de Minas Gerais (UFMG), este último sob orientação de Carlos Camarão. Entre 2016 e 2017 realizei pós-doutorado na Universidade Federal de Pelotas (UFPel), trabalhando com André Rauber Du Bois.

Interesses de pesquisa

Minha pesquisa concentra-se, de forma ampla, no projeto e na implementação de linguagens de programação. Tenho interesse particular na construção de software correto por construção usando assistentes de provas baseados em teoria de tipos, como Agda, Rocq (Coq) e Lean. Temas recentes incluem:

  • Teoria de linguagens formais e parsing — resultados mecanizados sobre expressões regulares, gramáticas livres de contexto, autômatos com pilha e Parsing Expression Grammars (PEGs);
  • Semântica e sistemas de tipos — metateoria mecanizada, inferência de tipos e geração de programas dirigida por tipos;
  • Verificação de programas — lógicas de programas, verificação de código de baixo nível e testes baseados em propriedades;
  • Programação funcional — bibliotecas Haskell e linguagens de domínio específico embutidas.

Estou sempre em busca de estudantes motivados interessados nesses temas. Fique à vontade para entrar em contato!

publicações selecionadas

  1. CGO
    Honey Potion: An eBPF Backend for Elixir
    Kael Soares Augusto, Vinícius Pacheco, Marcos A. Vieira, and 2 more authors
    In Proceedings of the 23rd ACM/IEEE International Symposium on Code Generation and Optimization (CGO ’25), 2025
    Abs DOI Bib Code

    This paper describes Honey Potion, a compiler that compiles Elixir to eBPF binaries. Translation must not only preserve semantics but also satisfy the eBPF verifier, which requires proofs of in-bounds memory accesses and termination; the translator relies on ensured termination to implement constant propagation, type specialization and partial evaluation.

  2. ITP
    Redex2Coq: Towards a Theory of Decidability of Redex’s Reduction Semantics
    Mallku Soldevila, Rodrigo Ribeiro, and Beta Ziliani
    In 15th International Conference on Interactive Theorem Proving (ITP 2024), 2024
    Abs DOI Bib Code

    We propose the first step in the development of a tool to automate the translation of Redex models into a semantically equivalent model in Coq, and to provide tactics to help in the certification of fundamental properties of such models. We code in Coq a primitive recursive definition of Redex’s matching algorithm and prove its correctness with respect to the original specification.

  3. Haskell
    Open Transactional Actions: Interacting with Non-transactional Resources in STM Haskell
    Jonathas Augusto de Oliveira Conceição, André Rauber Du Bois, Samuel da Silva Feitosa, and 2 more authors
    In Proceedings of the 15th ACM SIGPLAN International Haskell Symposium (Haskell ’22), 2022
    Abs DOI Bib

    This paper addresses the problem of accessing external resources from inside transactions in STM Haskell, and introduces Open Transactional Actions (OTAs), a framework for wrapping non-transactional resources in a transactional layer, with commit and abort handlers.

  4. COLA
    An Intrinsically-Typed Solution for the List-Machine Benchmark
    Samuel Feitosa and Rodrigo Ribeiro
    Journal of Computer Languages, 2021
    Abs Bib Code

    We use dependently-typed programming to build a verified interpreter for the list-machine benchmark in the Agda programming language, comparing the results with formalizations developed by Appel and Leroy, and extending the conference version with jump instructions.

  5. TOPLAS
    Type Inference for C: Applications to the Static Analysis of Incomplete Programs
    Leandro T. C. Melo, Rodrigo G. Ribeiro, Breno C. F. Guimarães, and 1 more author
    ACM Transactions on Programming Languages and Systems, 2020
    Abs Bib

    Type inference remains an unexplored subject in the realm of C. Parsing C requires not only syntactic but also semantic information, and C has an intricate type system. We present a unification-based framework for type inference in C with applications to the static analysis of incomplete programs.

  6. POPL
    Inference of Static Semantics for Incomplete C Programs
    Leandro T. C. Melo, Rodrigo G. Ribeiro, Marcus R. Araújo, and 1 more author
    Proceedings of the ACM on Programming Languages, 2018
    Abs DOI Bib PDF

    We present a unification-based type inference capable of dealing with C intricacies, which lets us reconstruct partial C programs into complete well-typed ones, enabling static analysis, stub generation and testing on incomplete code.
